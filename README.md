# SDG 7 — Global Electricity Access

Data analytics project completed during my Data Analytics
internship with International Sibling Society (ISS).

## Question
Which countries still lack full access to electricity in 2022,
and how wide is the gap between the bottom and everyone else?

## Data
UN Global SDG Indicators Database — Indicator 7.1.1
18,825 rows, 251 areas, 2000–2024

## Tools
Microsoft Excel, Microsoft Power BI

## What I did
- Cleaned the raw download and removed all regional aggregates
- Filtered to 2022, the newest year with complete reporting
- Built a world map with three colour bands and drill-through charts

## Findings
- Electricity poverty is concentrated in Sub-Saharan Africa
- South Sudan is lowest at 8.4% access
- 27 countries sit between 35% and 70%, where progress can move fastest# SDG7-Global-Electricity-Access
